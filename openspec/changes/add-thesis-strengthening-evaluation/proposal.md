## Why

`D:/download/by.docx` 将多层记忆、Windows 桌面感知与受控操作、跨端协同定义为毕业设计的三条主线。当前随机向量 benchmark 不能回答跨会话 Recall@5、旧版本误召回、真实 GUI 任务成功率和跨端一致性是否达到指标；缺少统一分母和实测证据会使后续强化无法比较。

## What Changes

- 新增离线评测记录契约和 CLI，读取实际采集或人工标注的 JSON 数据，逐项计算任务书中的三组指标。
- 记忆评测以 `memory_id + version_id` 标注答案，分别统计 Recall@5、含旧版本结果的查询比例、凭据违规入库、跨身份泄漏和拒答。
- GUI 评测分别报告元素定位与完整多步骤任务结果，并核验三类应用、60 个场景覆盖和未授权敏感操作。
- 跨端评测以同一已提交版本及接收端观测记录计算状态一致率和稳定网络同步延迟 P95，覆盖至少 50 组用例。
- 空记录、缺测、样本不足、非法输入和合成演示数据不得被报告为真实达标；输出指标、分母、覆盖和证据性质。
- 建立有源码依据的强化设计与 Luna 后续实施清单，明确本期代码只提供评测基础，实际运行模块增强分阶段执行。
