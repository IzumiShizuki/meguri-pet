# AstrBot 个人模式命令表

审计日期：2026-10-05（北京时间）。这里的个人模式指 **AstrBot 的 QQ 私聊**。服务器有 77 个插件源码目录；当前启用的平台是 **QQ 官方机器人（qq_official）和微信公众号（weixin_oc）**，没有启用个人 QQ 的 aiocqhttp。多数查询/娱乐命令具备私聊入口；群管、个人 QQ 特有 API、AstrBot LLM 工具/上下文插件不能靠路由改动变成 Core 能力。

此表基于服务器已安装源码、插件 README 和有限的无秘密配置检查。**目录存在不等于插件成功加载；私聊入口存在不等于外部 API/账号/图片音频投递已实测成功。** 已完成网关路由回归测试；未逐个请求外部网站、登录账号或向 QQ 发送测试消息。命令参数、重命名和启用状态仍以当前 AstrBot 配置为准。

网关 **0.6.0 已于 2026-10-05 14:16（北京时间）安装到服务器并重启生效**。启动日志确认新版网关初始化成功，Core 健康检查正常；直接加载已部署代码的 11 项合成事件路由检查全部通过。下述触发顺序已应用；真实 QQ 投递和外部插件接口尚未逐项实测。

## 触发顺序

1. `/meguri ...` 明确指定 Core（AstrBot 已去掉 `/` 时也能正确识别）。
2. 其他已匹配的插件命令/别名/正则，以及下面列出的链接、卡片、搜图和表情模板触发，先交给插件；网关不创建 Core turn，同时抑制默认 LLM 的额外回复。
3. 普通聊天进入原来的 Meguri Core 工作流。

注册命令推荐带 `/`。妻子插件的 `jrlp`/`jrlb` 和正则/BV/链接触发可直接发送。手动别名按完整命令和空白分隔的参数匹配；例如 `jrlp其他` 不匹配 `jrlp`。插件自己的权限、私聊/群聊限制、白名单及外部服务配置保持有效。

## 不能直接在当前私聊使用的功能

| 类别 | 插件/功能 | 原因 |
| --- | --- | --- |
| 群操作 | 群公告、入群/退群欢迎、群成员查询、谁@我、群画像、群日报/群漫画、组队“本群” | 需要真实群号/群历史/群成员；不伪造群上下文 |
| 个人 QQ 特有 API | 戳一戳、QQ 资料点赞、贴消息表情、部分“盒”、违规查询 | 依赖 aiocqhttp/个人 QQ API；当前 QQ 官方机器人不提供同样的接口 |
| AstrBot LLM 工具 | email_tool、部分 relationship、forward_reader、self_learning、persona_plus、provider 切换 | 相关工具和钩子属于 AstrBot LLM，网关使用的是 Meguri Core；命令管理入口让行也不代表模型能力接通 |
| 后台连接/维护 | Bilibili live、自动备份、部分上下文/日志插件 | 没有普通聊天命令或属于后台任务；不能给每条消息都授予所有权 |
